# 教培动画素材库

把每条视频里真正值得留下的东西留下来。

这不是一个把成片、截图和临时文件塞进硬盘的下载包。它是一套给教培内容团队用的收纳方法：把可以拆开再用的组件、镜头规则、字幕结构、提示词骨架和制作合同整理清楚；下次做同类题时，先查一查，再从已经想明白的地方继续。

目前它支持两条常见路线：

- **VOX 纸艺拼贴**：管理纸艺元素、层次关系、动作提示、镜头合同与可复用的画面语法。
- **二维杂志图解**：管理语义组件、组件内文字、字幕层、镜头合同和 Remotion 结构。

它和 [二维杂志图解视频制作 Skill](https://github.com/JasperMZ-Zcy/muzhi-editorial-magazine-skill) 是一前一后的搭档：

| 先做什么 | 用哪个 |
| --- | --- |
| 找到可复用的元素，说明它从哪里来、能怎么用、能不能公开 | 本仓库：教培动画素材库 |
| 把口播、字幕、镜头、组件和审核做成一条完整的视频 | [二维杂志图解视频制作 Skill](https://github.com/JasperMZ-Zcy/muzhi-editorial-magazine-skill) |

素材库不替代制作流程；制作 Skill 也不替代资产管理。一个解决“别从零开始”，一个解决“怎么把这一条做好”。

## 适合什么场景

- 升学规划、考研、高考、留学、职业教育等知识口播；
- 需要反复制作人物、物件、数字、步骤、因果、对比关系的动画；
- 已经做过几条视频，想把真正可复用的部分从项目里拆出来；
- 团队希望以后换主题、换人、换设备，仍然能找到同一套做法。

它不适合把未授权图库、别人视频截图、完整成片、学生隐私、账号数据或来路不清的灵感素材公开分发。

## 里面有什么

- 可安装的 Codex Skill：skill/education-animation-asset-library/
- 通用资产记录模板和逐镜交接模板
- 可直接改造成项目组件的 Remotion 示例
- 两条动画路线的选择说明
- 一份公开边界清单，以及本地自动扫描工具

这个公开仓库只放通用方法、空白模板和新编的示例结构。它**不包含**真实项目的成片、口播、原始素材、Flow 原片、音乐、字体、平台数据、客户数据或本机配置。

## 安装

准备好 Git、Python 和 Codex 后，在 PowerShell 中执行：

~~~powershell
$repo = Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'CodexSkills\education-animation-asset-library'
git clone https://github.com/JasperMZ-Zcy/education-animation-asset-library.git $repo
& "$repo\install.ps1" -NonInteractive
~~~

重新打开一个 Codex task 后，可以这样开始：

> 用教育动画素材库检查这个项目里哪些东西值得入库；只收能拆分复用的元素和模板，保留来源、复用条件与公开边界。

已有二维杂志图解项目时，也可以这样衔接：

> 先用教育动画素材库搜可复用组件和字幕规则，再按杂志插画产线完成这条视频。

## 使用方法

1. **先检索，再制作。** 不要因为找不到而立刻重画一个近似版本。
2. **只收可拆分的部分。** 最终成片和完整工程继续留在原项目。
3. **让记录跟着素材走。** 每个条目写清来源、用途、限制、权利状态和检索标签。
4. **默认内部可用，公开另审。** “能在团队项目里用”不等于“可以上传到公共仓库”。
5. **公开前再过一遍边界。** 自动扫描能发现明显问题，权利和隐私仍需要人来判断。

更完整的资产记录字段、路线选择和公开边界见 Skill 自带的 references 目录。

## 公开边界

下面这些内容只应留在私有库或原项目中：

- 完整视频、导出包、口播、原始音频和未授权音乐；
- 学生、客户、平台后台或账号相关资料；
- 外部参考、待核验素材和历史缺件；
- 含有本机路径、密钥、令牌、浏览器配置或项目内部信息的文件；
- 只能在某个具体题目、某个具体项目里成立的视觉或文字内容。

公开版的目标是帮助大家建立自己的库，而不是把别人的项目成果换个文件名搬走。

## 对已有制作 Skill 的说明

[二维杂志图解视频制作 Skill](https://github.com/JasperMZ-Zcy/muzhi-editorial-magazine-skill) 已经负责把录音、SRT 和定稿文案整理成稳定的语义镜头，并通过组件、字幕和审核把视频落下来。建议的顺序是：

~~~text
教培动画素材库：检索与挑选
        ↓
二维杂志图解视频制作 Skill：制作与验收
        ↓
把本次新长出的通用组件、合同和规则回填素材库
~~~

这样做不会让每条视频长得一模一样。库里保存的是可复用的结构和经验；新的主题、证据、叙事和视觉判断，仍然应当为这条视频单独完成。

## 参与改进

欢迎提交 Issue 或 Pull Request，尤其是：

- 某类资产为什么难以检索、难以复用；
- 哪些字段可以让交接更少返工；
- 哪些通用模板能被不同教培题材真正复用；
- 哪些公开边界需要补得更清楚。

请不要在 Issue、PR 或附件中上传未发布课程、学生信息、平台后台截图、账号凭据、完整项目或没有明确授权的素材。
